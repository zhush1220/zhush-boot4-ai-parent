# 动态切换数据源 —— 完整实现方案

> 项目：zhush-boot4-parent | Spring Boot 4.1.0 | MyBatis-Flex 1.11.8 | Druid 1.2.28
> 最后更新：2026-07-12

---

## 一、架构总览

```
┌──────────────────────────────────────────────────────────────┐
│                     应用层 (Service/Controller)                │
│   @UseDataSource("slave")  │  DataSourceKey.use("tenant_x")  │
├──────────────────────────┬───────────────────────────────────┤
│     声明式切换            │         编程式切换                  │
│  @UseDataSource 注解      │   DataSourceKey + AOP 切面         │
├──────────────────────────┴───────────────────────────────────┤
│                   FlexDataSource                              │
│           (MyBatis-Flex 内置，继承 AbstractRoutingDataSource)   │
├──────────┬──────────┬───────────┬────────────────────────────┤
│  master  │  slave   │ tenant_A  │  动态添加...                 │
│ (Druid)  │ (Druid)  │ (Druid)   │  (Druid)                    │
└──────────┴──────────┴───────────┴────────────────────────────┘
        ▲                          ▲
   YAML 静态配置              DataSourceManager 运行时管理
```

**核心能力：**

1. YAML 声明式多数据源配置，每个数据源独立 Druid 连接池
2. `@UseDataSource` 注解在 Mapper/Service/Controller 层声明式切换
3. `DataSourceKey.use()` 编程式动态切换（支持通配符负载均衡）
4. `DataSourceManager` 运行时动态添加/移除数据源
5. `sys_datasource` 表存储数据源元信息，启动自动挂载
6. `DataSourceMissingHandler` 数据源缺失兜底策略

**不需要引入** `dynamic-datasource-spring-boot-starter`，MyBatis-Flex 原生支持。

## 二、YAML 配置（application-dev.yaml 示例）

数据源配置从 `spring.datasource` 迁移到 `mybatis-flex.datasource` 下：

```yaml
server:
  port: 9166

spring:
  # Druid 全局监控配置（对所有数据源生效）
  datasource:
    druid:
      filter:
        stat:
          enabled: true
          log-slow-sql: true
          slow-sql-millis: 100
          merge-sql: true
        wall:
          enabled: true
          config:
            multi-statement-allow: true
      stat-view-servlet:
        enabled: true
        allow:
        url-pattern: /druid/*
        login-username: admin
        login-password: your_password

mybatis-flex:
  mapper-locations: classpath*:mapper/**/*.xml
  configuration:
    map-underscore-to-camel-case: true
    log-impl: org.apache.ibatis.logging.slf4j.Slf4jImpl

  # ==================== 多数据源配置 ====================
  datasource:
    # 主库（第一个数据源自动成为默认数据源）
    master:
      type: com.alibaba.druid.pool.DruidDataSource
      url: jdbc:mysql://localhost:3306/zhush_main?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
      username: root
      password: password
      initialSize: 5
      maxActive: 20
      minIdle: 5
      maxWait: 60000
      validationQuery: SELECT 1
      testWhileIdle: true

    # 从库（只读/报表）
    slave:
      type: com.alibaba.druid.pool.DruidDataSource
      url: jdbc:mysql://localhost:3306/zhush_slave?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
      username: readonly
      password: readonly_pass
      initialSize: 3
      maxActive: 10
      minIdle: 3
      maxWait: 60000
      validationQuery: SELECT 1
      testWhileIdle: true

    # 可按需继续添加更多数据源...
    # business-b:
    #   type: com.alibaba.druid.pool.DruidDataSource
    #   url: jdbc:mysql://192.168.1.100:3306/zhush_biz_b?...
    #   username: root
    #   password: biz_pass

logging:
  level:
    com.zhush: debug
    com.mybatisflex: debug

zhush:
  encrypt:
    enabled: true
    sm4-key: your-16-char-key!
```

**配置要点：**

- `type` 必须指定为 `com.alibaba.druid.pool.DruidDataSource`，MyBatis-Flex 据此创建 Druid 连接池实例。
- `master`（第一个数据源）是默认数据源，不带 `@UseDataSource` 的 Mapper/Service 都走它。
- Druid 连接池属性直接写 setter 对应的 key（驼峰命名：`initialSize`、`maxActive` 等）。
- Druid 监控（`filter`、`stat-view-servlet`）仍放在 `spring.datasource.druid` 下，由 `druid-spring-boot-4-starter` 统一管理。

## 三、数据源切换优先级

MyBatis-Flex 的数据源路由按以下优先级从高到低生效：

| 优先级 | 方式 | 使用位置 | 典型场景 |
|--------|------|---------|---------|
| 1 (最高) | `DataSourceKey.use("xxx")` | 代码中 | 多租户路由、编程式切换 |
| 2 | `@UseDataSource("xxx")` | 方法上 | 单个方法走不同库 |
| 3 | `@UseDataSource("xxx")` | 类上 | 整个 Mapper/Service 走同一库 |
| 4 (最低) | `@Table(dataSource="xxx")` | 实体类上 | 实体绑定固定数据源 |

## 四、声明式切换 —— @UseDataSource

### 4.1 Mapper 类级别

```java
package com.zhush.module.system.mapper;

import com.mybatisflex.annotation.UseDataSource;
import com.zhush.mybatis.core.mapper.BaseMapperX;
import org.apache.ibatis.annotations.Mapper;

/**
 * 报表数据 Mapper —— 整个类走 slave 数据源
 */
@Mapper
@UseDataSource("slave")
public interface ReportDataMapper extends BaseMapperX<ReportData> {
    // 所有方法默认走 slave
}
```

### 4.2 Mapper 方法级别

```java
package com.zhush.module.system.mapper;

import com.mybatisflex.annotation.UseDataSource;
import com.mybatisflex.core.query.QueryWrapper;
import com.zhush.mybatis.core.mapper.BaseMapperX;
import org.apache.ibatis.annotations.Mapper;

import java.util.List;

/**
 * 订单 Mapper —— 方法级别切换数据源
 */
@Mapper
public interface BizOrderMapper extends BaseMapperX<BizOrder> {

    // 默认走 master（无注解）

    /**
     * 查询业务库B的订单
     */
    @UseDataSource("business-b")
    default List<BizOrder> selectFromBizB() {
        return selectListByQuery(QueryWrapper.create());
    }
}
```

### 4.3 Service 级别

```java
package com.zhush.module.system.service;

import com.mybatisflex.annotation.UseDataSource;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

@Service
public class ReportService {

    private final ReportDataMapper reportDataMapper;

    public ReportService(ReportDataMapper reportDataMapper) {
        this.reportDataMapper = reportDataMapper;
    }

    @UseDataSource("slave")
    @Transactional(readOnly = true)
    public List<ReportData> getMonthlyReport() {
        return reportDataMapper.selectListByQuery(QueryWrapper.create());
    }
}
```

## 五、编程式动态切换 —— DataSourceKey

### 5.1 基本用法

```java
import com.mybatisflex.core.datasource.DataSourceKey;
import com.mybatisflex.core.row.Db;

// 方式一：try-finally（推荐，最安全）
try {
    DataSourceKey.use("slave");
    List<Row> rows = Db.selectAll("tb_account");
} finally {
    DataSourceKey.clear(); // 必须清理！线程池复用会导致数据源泄漏
}

// 方式二：通配符随机选择（负载均衡场景）
try {
    DataSourceKey.use("slave*"); // 随机选择 slave 开头的数据源
    // ...
} finally {
    DataSourceKey.clear();
}
```

### 5.2 工具类封装 —— DataSourceHelper

**文件路径：** `zhush-spring-boot-starter-mybatis/src/main/java/com/zhush/mybatis/core/datasource/DataSourceHelper.java`

```java
package com.zhush.mybatis.core.datasource;

import com.mybatisflex.core.datasource.DataSourceKey;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

import java.util.function.Supplier;

/**
 * 数据源切换工具类
 * <p>
 * 封装 DataSourceKey 的 try-finally 模式，确保线程安全。
 *
 * @author zhush
 * @since 2026/7/12
 */
public final class DataSourceHelper {

    private static final Logger log = LoggerFactory.getLogger(DataSourceHelper.class);

    private DataSourceHelper() {
    }

    /**
     * 在指定数据源上执行操作并返回结果
     *
     * @param dataSourceName 数据源名称
     * @param supplier       要执行的操作
     * @return 操作结果
     */
    public static <T> T executeOn(String dataSourceName, Supplier<T> supplier) {
        try {
            DataSourceKey.use(dataSourceName);
            return supplier.get();
        } finally {
            DataSourceKey.clear();
        }
    }

    /**
     * 在指定数据源上执行操作（无返回值）
     *
     * @param dataSourceName 数据源名称
     * @param runnable       要执行的操作
     */
    public static void executeOn(String dataSourceName, Runnable runnable) {
        try {
            DataSourceKey.use(dataSourceName);
            runnable.run();
        } finally {
            DataSourceKey.clear();
        }
    }

    /**
     * 在默认数据源上执行操作
     * <p>
     * 用于在已切换数据源的上下文中，临时回到默认数据源执行。
     *
     * @param supplier 要执行的操作
     * @return 操作结果
     */
    public static <T> T executeOnDefault(Supplier<T> supplier) {
        try {
            DataSourceKey.use("master");
            return supplier.get();
        } finally {
            DataSourceKey.clear();
        }
    }
}
```

**使用示例：**

```java
// 查询从库
List<ReportData> data = DataSourceHelper.executeOn("slave", () ->
    reportMapper.selectListByQuery(QueryWrapper.create())
);

// 在从库上执行写操作
DataSourceHelper.executeOn("slave", () -> {
    reportMapper.insert(reportData);
});
```

## 六、多租户数据源路由切面

**文件路径：** `zhush-spring-boot-starter-mybatis/src/main/java/com/zhush/mybatis/core/datasource/TenantDataSourceAspect.java`

```java
package com.zhush.mybatis.core.datasource;

import com.mybatisflex.core.datasource.DataSourceKey;
import jakarta.servlet.http.HttpServletRequest;
import org.aspectj.lang.annotation.After;
import org.aspectj.lang.annotation.Aspect;
import org.aspectj.lang.annotation.Before;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.stereotype.Component;
import org.springframework.web.context.request.RequestContextHolder;
import org.springframework.web.context.request.ServletRequestAttributes;

/**
 * 多租户数据源自动路由切面
 * <p>
 * 从请求头 {@code X-Tenant-Id} 提取租户标识，自动切换到对应数据源。
 * 数据源 key 约定格式：{@code tenant_{tenantId}}
 * <p>
 * 通过配置 {@code zhush.datasource.tenant.enabled=true} 开启。
 *
 * @author zhush
 * @since 2026/7/12
 */
@Aspect
@Component
@ConditionalOnProperty(name = "zhush.datasource.tenant.enabled", havingValue = "true")
public class TenantDataSourceAspect {

    private static final Logger log = LoggerFactory.getLogger(TenantDataSourceAspect.class);

    /**
     * 请求头名称
     */
    private static final String TENANT_HEADER = "X-Tenant-Id";

    /**
     * 数据源 key 前缀
     */
    private static final String DS_PREFIX = "tenant_";

    @Before("@within(org.springframework.web.bind.annotation.RestController) " +
            "|| @within(org.springframework.stereotype.Controller)")
    public void before() {
        ServletRequestAttributes attrs =
                (ServletRequestAttributes) RequestContextHolder.getRequestAttributes();
        if (attrs == null) {
            return;
        }

        HttpServletRequest request = attrs.getRequest();
        String tenantId = request.getHeader(TENANT_HEADER);
        if (tenantId != null && !tenantId.isBlank()) {
            String dsKey = DS_PREFIX + tenantId;
            DataSourceKey.use(dsKey);
            log.debug("租户路由 -> 数据源 [{}]", dsKey);
        }
        // 未携带租户头时不切换，走默认数据源
    }

    @After("@within(org.springframework.web.bind.annotation.RestController) " +
           "|| @within(org.springframework.stereotype.Controller)")
    public void after() {
        DataSourceKey.clear();
    }
}
```

**开启方式（application.yaml）：**

```yaml
zhush:
  datasource:
    tenant:
      enabled: true   # 开启多租户路由
```

## 七、运行时动态管理 —— DataSourceManager

**文件路径：** `zhush-spring-boot-starter-mybatis/src/main/java/com/zhush/mybatis/core/datasource/DataSourceManager.java`

```java
package com.zhush.mybatis.core.datasource;

import com.alibaba.druid.pool.DruidDataSource;
import com.mybatisflex.core.FlexGlobalConfig;
import com.mybatisflex.core.datasource.FlexDataSource;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.stereotype.Component;

import javax.sql.DataSource;
import java.sql.SQLException;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;

/**
 * 数据源动态管理器
 * <p>
 * 支持在应用运行时动态添加、移除、查询数据源。
 * 适用于多租户动态注册、管理后台配置数据源等场景。
 * <p>
 * 线程安全：内部使用 ConcurrentHashMap 跟踪动态数据源。
 *
 * @author zhush
 * @since 2026/7/12
 */
@Component
public class DataSourceManager {

    private static final Logger log = LoggerFactory.getLogger(DataSourceManager.class);

    /** 动态数据源注册表（区分于 YAML 静态配置的数据源） */
    private final Set<String> dynamicDataSources = ConcurrentHashMap.newKeySet();

    // ===================== 核心 API =====================

    /**
     * 动态添加 Druid 数据源（使用默认连接池参数）
     */
    public void addDruidDataSource(String name, String url, String username, String password) {
        addDruidDataSource(name, url, username, password, null);
    }

    /**
     * 动态添加 Druid 数据源（带自定义连接池参数）
     *
     * @param name       数据源唯一名称
     * @param url        JDBC URL
     * @param username   用户名
     * @param password   密码
     * @param properties 额外 Druid 属性（可为 null）
     *                   支持的 key：initialSize, maxActive, minIdle, maxWait
     */
    public void addDruidDataSource(String name, String url, String username, String password,
                                   Map<String, String> properties) {
        if (containsDataSource(name)) {
            log.warn("数据源 [{}] 已存在，跳过重复注册", name);
            return;
        }

        DruidDataSource dataSource = new DruidDataSource();
        dataSource.setUrl(url);
        dataSource.setUsername(username);
        dataSource.setPassword(password);

        // 默认连接池参数
        dataSource.setInitialSize(3);
        dataSource.setMaxActive(10);
        dataSource.setMinIdle(2);
        dataSource.setMaxWait(60_000);
        dataSource.setValidationQuery("SELECT 1");
        dataSource.setTestWhileIdle(true);
        dataSource.setTimeBetweenEvictionRunsMillis(60_000);
        dataSource.setMinEvictableIdleTimeMillis(300_000);

        // 覆盖自定义属性
        if (properties != null) {
            applyProperties(dataSource, properties);
        }

        try {
            dataSource.init();
        } catch (SQLException e) {
            throw new RuntimeException("数据源 [" + name + "] 初始化失败: " + e.getMessage(), e);
        }

        getFlexDataSource().addDataSource(name, dataSource);
        dynamicDataSources.add(name);
        log.info("动态数据源 [{}] 注册成功 -> {}", name, url);
    }

    /**
     * 移除动态数据源并释放连接池资源
     */
    public void removeDataSource(String name) {
        DataSource removed = getFlexDataSource().removeDataSource(name);
        if (removed instanceof DruidDataSource druid) {
            druid.close();
            log.info("动态数据源 [{}] 已移除并释放连接池", name);
        } else if (removed != null) {
            log.info("动态数据源 [{}] 已移除（非 Druid 类型: {}）", name, removed.getClass().getName());
        } else {
            log.warn("动态数据源 [{}] 不存在，无需移除", name);
        }
        dynamicDataSources.remove(name);
    }

    /**
     * 查询所有已注册的数据源名称（含静态 + 动态）
     */
    public Set<String> getDataSourceNames() {
        return getFlexDataSource().getDataSourceMap().keySet();
    }

    /**
     * 查询所有动态注册的数据源名称
     */
    public Set<String> getDynamicDataSourceNames() {
        return Set.copyOf(dynamicDataSources);
    }

    /**
     * 判断数据源是否存在
     */
    public boolean containsDataSource(String name) {
        return getFlexDataSource().getDataSourceMap().containsKey(name);
    }

    // ===================== 内部方法 =====================

    private FlexDataSource getFlexDataSource() {
        FlexDataSource ds = FlexGlobalConfig.getDefaultConfig().getDataSource();
        if (ds == null) {
            throw new IllegalStateException(
                    "FlexDataSource 未初始化，请确保应用已完全启动后再调用此方法");
        }
        return ds;
    }

    private void applyProperties(DruidDataSource ds, Map<String, String> properties) {
        String val;
        if ((val = properties.get("initialSize")) != null) {
            ds.setInitialSize(Integer.parseInt(val));
        }
        if ((val = properties.get("maxActive")) != null) {
            ds.setMaxActive(Integer.parseInt(val));
        }
        if ((val = properties.get("minIdle")) != null) {
            ds.setMinIdle(Integer.parseInt(val));
        }
        if ((val = properties.get("maxWait")) != null) {
            ds.setMaxWait(Long.parseLong(val));
        }
    }
}
```

## 八、数据源元信息表 + 启动自动挂载

### 8.1 建表 DDL

**文件路径：** `zhush-server/src/main/resources/db/sys_datasource.sql`

```sql
-- ============================================================
-- 数据源配置表
-- 用于存储动态数据源的连接信息，应用启动时自动挂载
-- ============================================================
CREATE TABLE `sys_datasource` (
  `id`           BIGINT       NOT NULL                    COMMENT '主键(雪花ID)',
  `name`         VARCHAR(64)  NOT NULL                    COMMENT '数据源名称(唯一标识，如 tenant_A)',
  `url`          VARCHAR(512) NOT NULL                    COMMENT 'JDBC URL',
  `username`     VARCHAR(128) NOT NULL                    COMMENT '用户名',
  `password`     VARCHAR(256) NOT NULL                    COMMENT '密码(建议加密存储)',
  `driver_class` VARCHAR(128) DEFAULT NULL                COMMENT 'JDBC驱动类名(可选，一般从URL自动识别)',
  `pool_type`    VARCHAR(32)  NOT NULL DEFAULT 'druid'    COMMENT '连接池类型: druid / hikari',
  `initial_size` INT          NOT NULL DEFAULT 3          COMMENT '初始连接数',
  `max_active`   INT          NOT NULL DEFAULT 10         COMMENT '最大连接数',
  `min_idle`     INT          NOT NULL DEFAULT 2          COMMENT '最小空闲连接数',
  `max_wait`     INT          NOT NULL DEFAULT 60000      COMMENT '获取连接最大等待时间(ms)',
  `status`       TINYINT      NOT NULL DEFAULT 1          COMMENT '状态: 0-禁用 1-启用',
  `remark`       VARCHAR(256) DEFAULT NULL                COMMENT '备注',
  `create_by`    BIGINT       DEFAULT NULL                COMMENT '创建人',
  `create_time`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_by`    BIGINT       DEFAULT NULL                COMMENT '更新人',
  `update_time`  DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  `is_delete`    TINYINT      NOT NULL DEFAULT 0          COMMENT '逻辑删除: 0-正常 1-已删除',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_name` (`name`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci COMMENT='数据源配置表';
```

### 8.4 启动自动挂载

**文件路径：** `zhush-spring-boot-starter-mybatis/src/main/java/com/zhush/mybatis/core/datasource/DataSourceAutoLoader.java`

```java
package com.zhush.mybatis.core.datasource;

import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.boot.autoconfigure.condition.ConditionalOnBean;
import org.springframework.context.annotation.Configuration;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

/**
 * 启动时从数据库加载数据源配置并动态注册
 * <p>
 * 依赖 SysDatasourceMapper（由业务模块提供），
 * 通过 @ConditionalOnBean 确保只在 Mapper 存在时才生效。
 *
 * @author zhush
 * @since 2026/7/12
 */
@Configuration
@ConditionalOnBean(name = "sysDatasourceMapper")
public class DataSourceAutoLoader implements ApplicationRunner {

    private static final Logger log = LoggerFactory.getLogger(DataSourceAutoLoader.class);

    private final Object sysDatasourceMapper;  // 通过名称注入，避免硬依赖业务模块
    private final DataSourceManager dataSourceManager;

    public DataSourceAutoLoader(Object sysDatasourceMapper,
                                DataSourceManager dataSourceManager) {
        this.sysDatasourceMapper = sysDatasourceMapper;
        this.dataSourceManager = dataSourceManager;
    }

    @Override
    @SuppressWarnings("unchecked")
    public void run(ApplicationArguments args) {
        try {
            // 反射调用 selectEnabledList()，避免编译期依赖业务模块
            var method = sysDatasourceMapper.getClass().getMethod("selectEnabledList");
            List<?> list = (List<?>) method.invoke(sysDatasourceMapper);

            if (list == null || list.isEmpty()) {
                log.info("无动态数据源配置，跳过自动挂载");
                return;
            }

            int success = 0;
            for (Object ds : list) {
                try {
                    // 反射读取属性
                    String name = (String) ds.getClass().getMethod("getName").invoke(ds);
                    String url = (String) ds.getClass().getMethod("getUrl").invoke(ds);
                    String username = (String) ds.getClass().getMethod("getUsername").invoke(ds);
                    String password = (String) ds.getClass().getMethod("getPassword").invoke(ds);
                    Integer initialSize = (Integer) ds.getClass().getMethod("getInitialSize").invoke(ds);
                    Integer maxActive = (Integer) ds.getClass().getMethod("getMaxActive").invoke(ds);
                    Integer minIdle = (Integer) ds.getClass().getMethod("getMinIdle").invoke(ds);
                    Integer maxWait = (Integer) ds.getClass().getMethod("getMaxWait").invoke(ds);

                    Map<String, String> props = new HashMap<>();
                    if (initialSize != null) props.put("initialSize", String.valueOf(initialSize));
                    if (maxActive != null) props.put("maxActive", String.valueOf(maxActive));
                    if (minIdle != null) props.put("minIdle", String.valueOf(minIdle));
                    if (maxWait != null) props.put("maxWait", String.valueOf(maxWait));

                    dataSourceManager.addDruidDataSource(name, url, username, password, props);
                    success++;
                } catch (Exception e) {
                    log.error("自动挂载数据源失败: {}", e.getMessage());
                }
            }
            log.info("数据源自动挂载完成，成功 {}/{}", success, list.size());

        } catch (Exception e) {
            log.warn("数据源自动挂载未执行: {}", e.getMessage());
        }
    }
}
```

> **更简洁的替代方案：** 如果业务模块已经可以直接依赖 `DataSourceManager`，可以不用反射，改为在业务模块中直接写 `ApplicationRunner`：

```java
// 在 zhush-module-system 中直接写（推荐）
package com.zhush.module.system.config;

import com.zhush.module.system.entity.SysDatasource;
import com.zhush.module.system.mapper.SysDatasourceMapper;
import com.zhush.mybatis.core.datasource.DataSourceManager;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.context.annotation.Configuration;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

@Configuration
public class DatasourceLoaderConfig implements ApplicationRunner {

    private final SysDatasourceMapper mapper;
    private final DataSourceManager manager;

    public DatasourceLoaderConfig(SysDatasourceMapper mapper, DataSourceManager manager) {
        this.mapper = mapper;
        this.manager = manager;
    }

    @Override
    public void run(ApplicationArguments args) {
        List<SysDatasource> list = mapper.selectEnabledList();
        for (SysDatasource ds : list) {
            Map<String, String> props = new HashMap<>();
            props.put("initialSize", String.valueOf(ds.getInitialSize()));
            props.put("maxActive", String.valueOf(ds.getMaxActive()));
            props.put("minIdle", String.valueOf(ds.getMinIdle()));
            props.put("maxWait", String.valueOf(ds.getMaxWait()));

            manager.addDruidDataSource(ds.getName(), ds.getUrl(),
                    ds.getUsername(), ds.getPassword(), props);
        }
    }
}
```

## 九、数据源缺失兜底 —— DataSourceMissingHandler

**文件路径：** `zhush-spring-boot-starter-mybatis/src/main/java/com/zhush/mybatis/config/DataSourceMissingHandlerAutoConfiguration.java`

```java
package com.zhush.mybatis.config;

import com.mybatisflex.core.FlexGlobalConfig;
import com.zhush.mybatis.core.datasource.DataSourceManager;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.boot.ApplicationArguments;
import org.springframework.boot.ApplicationRunner;
import org.springframework.context.annotation.Configuration;

/**
 * 注册数据源缺失处理器
 * <p>
 * 当 @UseDataSource 或 DataSourceKey.use() 指定的数据源不存在时，
 * 回退到默认数据源并记录告警日志（而非直接抛异常）。
 *
 * @author zhush
 * @since 2026/7/12
 */
@Configuration
public class DataSourceMissingHandlerAutoConfiguration implements ApplicationRunner {

    private static final Logger log = LoggerFactory.getLogger("DataSourceMissingHandler");

    @Override
    public void run(ApplicationArguments args) {
        FlexGlobalConfig.getDefaultConfig().setDataSourceMissingHandler(
            (flexDataSource, dsKey) -> {
                log.warn("数据源 [{}] 不存在，已回退到默认数据源。请检查配置。", dsKey);
                // 不做任何操作 -> MyBatis-Flex 自动回退到默认数据源
            }
        );
        log.info("数据源缺失处理器已注册（回退到默认数据源）");
    }
}
```

## 十、事务管理注意事项

### 10.1 单数据源事务（正常工作）

```java
@Service
@UseDataSource("master")
public class OrderService {
    @Transactional
    public void createOrder(Order order) {
        orderMapper.insert(order);
        orderDetailMapper.insertBatch(order.getDetails());
    }
}
```

### 10.2 跨数据源事务（不支持）

`@Transactional` **不支持跨数据源**。同一个事务方法内只能操作一个数据源。

如果方法内通过 `DataSourceKey.use()` 切换了数据源，`@Transactional` 只作用于切换前的数据源，切换后的操作不受事务保护。

**建议：**
- 不同数据源的操作拆分到不同的 Service 方法中，各自管理事务。
- 如果必须跨库一致性，引入 Seata（MyBatis-Flex 支持 Seata AT 模式）。

### 10.3 编程式切换时的事务安全

```java
// 错误示范：事务只保护 master，slave 上的操作没有事务
@Transactional
public void syncData() {
    orderMapper.insert(order);                     // master，有事务
    DataSourceKey.use("slave");
    reportMapper.insert(report);                   // slave，无事务！
    DataSourceKey.clear();
}

// 正确做法：拆成两个方法
public void syncData() {
    saveToMaster(order);      // @Transactional
    saveToSlave(report);      // @Transactional + @UseDataSource("slave")
}
```

## 十二、典型使用场景速查

| 场景 | 推荐方式 | 代码示例 |
|------|---------|---------|
| 主从分离，固定数据源 | YAML 配 master/slave + `@UseDataSource` | `@UseDataSource("slave")` 在报表 Mapper 上 |
| 按模块隔离数据源 | `@UseDataSource` 在 Mapper 类上 | 系统模块 master，报表模块 slave |
| 按实体绑定数据源 | `@Table(dataSource="xxx")` | 跨库实体固定走对应库 |
| 多租户动态路由 | AOP 切面 + 请求头 `X-Tenant-Id` | `TenantDataSourceAspect` 自动切换 |
| 管理后台动态配置 | `sys_datasource` 表 + `DataSourceManager` | 启动自动挂载 + API 增删 |
| 代码中临时切换 | `DataSourceHelper.executeOn()` | 定时任务跨库查询/同步 |
| 通配符负载均衡 | `DataSourceKey.use("slave*")` | 随机选择 slave 开头的库 |
