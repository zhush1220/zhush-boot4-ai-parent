# 接口幂等与文件上传实现说明

> 环境：Spring Boot 4.1.0 / JDK 21 / MyBatis-Flex / Sa-Token / Redis（Redisson）
> 关联接口文档见《接口幂等与文件上传接口文档.md》

---

## 一、接口幂等性

### 1.1 方案设计

采用 **请求指纹 + Redis SET NX 原子抢占** 方案（无需前端先取 Token，接入成本最低）：

1. 在提交类接口方法上标注 `@Idempotent` 注解；
2. `IdempotentAspect` 切面拦截，按「接口标识 + 登录用户 + 参数指纹（+ 自定义 key）」生成去重键，取 MD5 后拼前缀 `zhush:idempotent:`；
   - 接口标识：`request.getRequestURI() + ":" + request.getMethod()`；
   - 参数指纹：过滤 `MultipartFile` / Servlet 对象 / `BindingResult` 等不可序列化参数后，其余参数 JSON 序列化取 MD5；
   - 登录用户：由 `IdempotentUserResolver` SPI 提供，内置 `SatokenIdempotentUserResolver` 返回 `admin:{id}` / `member:{id}` / `anonymous`，无 Sa-Token 环境自动降级匿名；
3. 通过 `RedisCache.setIfAbsent(key, "1", window)`（底层 Redis `SET NX EX`）原子抢占：
   - 抢占成功 → 放行执行业务；
   - 抢占失败 → 抛出 `ServiceException(GlobalErrorCode.REPEATED_REQUEST, 自定义 message)`，由全局异常处理器返回错误码 `1000409`；
4. 业务执行抛异常时，若 `clearOnFailure = true`（默认）自动清除去重键，允许用户修正后重试。

### 1.2 注解能力

```java
@Idempotent(
    timeout = 5,                          // 幂等时间窗口
    timeUnit = TimeUnit.SECONDS,          // 窗口单位
    dimension = IdempotentDimension.ARGS, // 去重维度
    key = "",                             // 自定义 key（参与指纹计算）
    message = "请勿重复提交，请稍后再试",    // 重复请求提示
    clearOnFailure = true                 // 业务异常后清除去重键，允许重试
)
```

| 去重维度 | 去重键构成 | 典型场景 |
| --- | --- | --- |
| `ARGS`（默认） | 接口 + 用户 + 参数指纹 | 表单/JSON 提交：相同内容视为重复，不同内容互不影响 |
| `USER` | 接口 + 用户 | 点赞/报名：同一用户窗口期内仅一次 |
| `INTERFACE` | 仅接口 | 全局锁：窗口期内任何请求仅放行一次（如批量结算） |

### 1.3 已接入接口

- **管理端**（zhush-module-system）：用户/角色/部门/菜单的新增、修改、删除，用户分配角色、重置密码、修改状态，角色分配菜单/数据范围，OAuth2 客户端新增/修改/删除/重置密钥，文件上传/删除；
- **会员端**（zhush-module-member）：`/member/auth/login`、`/member/auth/wx-mini-login`（`timeout = 10`）；
- **会员端文件**：`/member/file/upload`、`/member/file/{id}` 删除（`timeout = 3`）。

### 1.4 使用示例

```java
@PostMapping
@Idempotent // 默认 5 秒窗口、ARGS 维度
public Result<Long> create(@RequestBody @Valid XxxParam param) { ... }

// 自定义窗口与提示
@PutMapping("/reset-secret/{id}")
@Idempotent(timeout = 10, message = "密钥重置中，请勿重复提交")
public Result<Oauth2ClientSecretVO> resetSecret(@PathVariable Long id) { ... }

// USER 维度：同一用户 60 秒内仅一次
@Idempotent(timeout = 60, dimension = IdempotentDimension.USER)
public Result<Void> signUp() { ... }
```

重复请求返回（HTTP 200 + 业务错误码）：

```json
{ "code": 1000409, "message": "请勿重复提交，请稍后再试", "data": null }
```

## 二、文件上传

### 2.1 方案设计

- **存储抽象**：自研 `FileStorage` SPI（未引入 x-file-storage），接口方法 `getType() / upload() / delete()`，内置 4 个实现：本地磁盘、阿里云 OSS、七牛云、华为云 OBS；
- **切换方式**：`zhush.file.primary` 指定默认存储平台（`local` / `aliyun-oss` / `qiniu` / `huawei-obs`），改配置即可切换，业务代码零改动；
- **上传流程**：`FileClient.upload()` 校验（非空 → 大小 → 扩展名白名单）→ 生成相对路径 `yyyy/MM/dd/{uuid}.{ext}` → 委托 primary 存储上传 → 返回 `FileUploadResult`；
- **落库**：`FileService.uploadFile()` 上传成功后写入 `infra_file` 表（含存储类型、上传人类型/ID），记录管理端与会员端上传来源；
- **本地访问**：本地存储时自动注册静态资源映射（默认 `/files/**` → `file:D:/zhush/upload/`），该路径不在 `/admin/**`、`/member/**` 鉴权前缀内，可直接访问；
- **权限隔离**：会员端删除/详情校验文件归属（仅限本人上传），分页强制限定 `user_type = member` 且 `user_id = 当前登录会员`；管理端由 `@SaCheckPermission` 按 `system:file:*` 权限码控制。

### 2.2 数据表

`sql/06_infra_file.sql`（遵循现有脚本命名规范）：

| 字段 | 说明 |
| --- | --- |
| id | 雪花 ID 主键 |
| name | 原始文件名 |
| path | 相对存储路径（yyyy/MM/dd/uuid.ext） |
| url | 文件访问 URL |
| ext / content_type / size | 扩展名 / MIME / 字节大小 |
| storage_type | local / aliyun-oss / qiniu / huawei-obs |
| user_type / user_id | 上传人类型（admin/member）与 ID |
| create_by / create_time / update_by / update_time / is_delete | 公共字段（is_delete 逻辑删除） |

索引：`idx_user(user_type, user_id)`、`idx_storage_type`、`idx_create_time`。

### 2.3 已知限制

- 七牛云删除需 BucketManager 管理凭证，当前实现为尽力而为（仅记录日志），如需强一致删除请在七牛控制台或补充管理凭证实现；
- 云存储 AK/SK 均为占位符，生产建议通过 jasypt 加密或环境变量注入。

## 四、配置说明

### 4.1 幂等（application-dev.yaml）

```yaml
zhush:
  idempotent:
    enabled: true   # 总开关，默认开启；false 时切面不装配
```

### 4.2 文件存储（application-dev.yaml）

```yaml
spring:
  servlet:
    multipart:
      max-file-size: 50MB      # 与 zhush.file.max-size 保持一致
      max-request-size: 100MB

zhush:
  file:
    enabled: true
    primary: local             # 切换存储：local / aliyun-oss / qiniu / huawei-obs
    max-size: 52428800         # 单文件上限（字节），默认 50MB
    # allowed-extensions: jpg,png,pdf   # 扩展名白名单，不配则不限制
    local:
      enabled: true
      base-path: D:/zhush/upload/
      domain: http://localhost:9166/files/
      url-path: /files/**
    aliyun-oss:
      enabled: false
      endpoint: your-endpoint
      access-key-id: your-access-key-id
      access-key-secret: your-access-key-secret
      bucket-name: your-bucket-name
      domain: ""               # 为空时按 https://{bucket}.{endpoint}/ 拼接
    qiniu:
      enabled: false
      access-key: your-access-key
      secret-key: your-secret-key
      bucket: your-bucket
      domain: https://your-domain/
    huawei-obs:
      enabled: false
      endpoint: your-endpoint
      access-key: your-access-key
      secret-key: your-secret-key
      bucket-name: your-bucket-name
      domain: ""
```

### 4.3 切换云存储步骤

1. 执行 `sql/06_infra_file.sql` 建表；
2. 将目标平台 `enabled: true` 并填入真实 endpoint / AK / SK / bucket；
3. `zhush.file.primary` 改为对应类型（如 `aliyun-oss`）；
4. 重启服务，历史文件记录保留（`storage_type` 字段标识各自来源）。
