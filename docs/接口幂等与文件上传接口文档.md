# 接口幂等与文件上传接口文档

> 统一约定：
> - 基础路径：`http://localhost:9166`（dev 环境）
> - 响应结构：`{ "code": 0, "message": "success", "data": ... }`，`code = 0` 表示成功
> - 管理端接口前缀 `/admin/**`：请求头携带管理端 Sa-Token（`satoken`），且需对应权限码
> - 会员端接口前缀 `/member/**`：请求头携带会员端令牌
> - 分页参数继承 `BaseQuery`：`pageNum`（默认 1）、`pageSize`（默认 10）
> - 分页返回：`{ "list": [...], "total": 总记录数 }`

---

## 一、管理端-文件管理（/admin/system/file）

### 1.1 上传文件

- **POST** `/admin/system/file/upload`
- 权限：`system:file:create`
- 幂等：3 秒窗口，重复提交返回 `1000409`
- 请求：`multipart/form-data`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| file | file | 是 | 待上传文件（≤ 50MB） |

响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1821345678901234567,
    "name": "合同扫描件.pdf",
    "path": "2026-08-12/9f8e7d6c5b4a.pdf",
    "url": "http://localhost:9166/files/2026-08-12/9f8e7d6c5b4a.pdf",
    "ext": "pdf",
    "contentType": "application/pdf",
    "size": 1048576,
    "storageType": "local",
    "userType": "admin",
    "userId": 1,
    "createTime": "2026-08-12T10:30:00"
  }
}
```

### 1.2 删除文件

- **DELETE** `/admin/system/file/{id}`
- 权限：`system:file:delete`
- 幂等：3 秒窗口
- 行为：存储侧物理删除 + 数据库逻辑删除（`is_delete = 1`）

响应示例：

```json
{ "code": 0, "message": "success", "data": null }
```

### 1.3 文件详情

- **GET** `/admin/system/file/{id}`
- 权限：`system:file:query`

响应示例：同 1.1 的 `data` 结构。

### 1.4 文件分页

- **GET** `/admin/system/file/page`
- 权限：`system:file:query`

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| pageNum | int | 否 | 页码，默认 1 |
| pageSize | int | 否 | 每页大小，默认 10 |
| name | string | 否 | 原始文件名（模糊匹配） |
| storageType | string | 否 | local / aliyun-oss / qiniu / huawei-obs |
| userType | string | 否 | admin / member |

请求示例：`GET /admin/system/file/page?pageNum=1&pageSize=10&name=合同`

响应示例：

```json
{
  "code": 0,
  "message": "success",
  "data": {
    "list": [
      {
        "id": 1821345678901234567,
        "name": "合同扫描件.pdf",
        "path": "2026-08-12/9f8e7d6c5b4a.pdf",
        "url": "http://localhost:9166/files/2026-08-12/9f8e7d6c5b4a.pdf",
        "ext": "pdf",
        "contentType": "application/pdf",
        "size": 1048576,
        "storageType": "local",
        "userType": "admin",
        "userId": 1,
        "createTime": "2026-08-12T10:30:00"
      }
    ],
    "total": 1
  }
}
```

## 二、会员端-文件（/member/file）

> 会员端仅能操作**本人上传**的文件，由服务端强制校验归属；分页仅返回本人文件。

### 2.1 上传文件

- **POST** `/member/file/upload`
- 幂等：3 秒窗口，重复提交返回 `1000409`
- 请求/响应：同管理端 1.1（`userType = member`，`userId` 为当前登录会员 ID）

### 2.2 删除文件（仅限本人）

- **DELETE** `/member/file/{id}`
- 幂等：3 秒窗口
- 非本人文件返回 `1001702`

### 2.3 文件详情（仅限本人）

- **GET** `/member/file/{id}`
- 非本人文件返回 `1001702`

### 2.4 我的文件分页

- **GET** `/member/file/page`
- 参数：同管理端 1.4（`userType` 参数对会员端无效，服务端强制限定为本人）

## 三、本地文件访问

- **GET** `/files/**`（如 `http://localhost:9166/files/2026-08-12/9f8e7d6c5b4a.pdf`）
- 仅本地存储（`zhush.file.primary = local`）时生效，由静态资源映射对外提供；不在登录校验前缀内，可直接访问。
- 云存储（OSS / 七牛 / OBS）场景直接使用上传返回的 `url`。

## 四、幂等接入接口清单（重复提交统一返回 1000409）

| 端 | 接口 | 窗口 |
| --- | --- | --- |
| 管理端 | `POST /admin/system/user`、`PUT /admin/system/user`、`DELETE /admin/system/user/{id}`、`PUT /admin/system/user/assign-role`、`PUT /admin/system/user/reset-password`、`PUT /admin/system/user/update-status` | 5s |
| 管理端 | `POST /admin/system/role`、`PUT /admin/system/role`、`DELETE /admin/system/role/{id}`、`PUT /admin/system/role/assign-menu`、`PUT /admin/system/role/assign-data-scope` | 5s |
| 管理端 | `POST /admin/system/dept`、`PUT /admin/system/dept`、`DELETE /admin/system/dept/{id}` | 5s |
| 管理端 | `POST /admin/system/menu`、`PUT /admin/system/menu`、`DELETE /admin/system/menu/{id}` | 5s |
| 管理端 | `POST /admin/system/oauth2-client`、`PUT /admin/system/oauth2-client`、`DELETE /admin/system/oauth2-client/{id}` | 5s |
| 管理端 | `PUT /admin/system/oauth2-client/reset-secret/{id}` | 10s |
| 管理端 | `POST /admin/system/file/upload`、`DELETE /admin/system/file/{id}` | 3s |
| 会员端 | `POST /member/auth/login`、`POST /member/auth/wx-mini-login` | 10s |
| 会员端 | `POST /member/file/upload`、`DELETE /member/file/{id}` | 3s |

重复提交响应示例：

```json
{ "code": 1000409, "message": "请勿重复提交，请稍后再试", "data": null }
```

> 说明：默认 ARGS 维度（接口 + 用户 + 参数指纹），相同内容窗口期内视为重复；业务执行失败时去重键自动清除，允许修正后重试。

## 五、错误码说明

### 5.1 全局错误码（GlobalErrorCode）

| 错误码 | 常量 | 说明 | 触发场景 |
| --- | --- | --- | --- |
| 1000409 | REPEATED_REQUEST | 重复请求，请勿重复提交 | 幂等窗口内重复提交（message 可被注解自定义覆盖） |
| 1000430 | FILE_EMPTY | 上传文件不能为空 | 未选择文件或空文件 |
| 1000431 | FILE_TYPE_UNSUPPORTED | 不支持的文件类型：{0} | 扩展名不在白名单（配置了 allowed-extensions 时） |
| 1000432 | FILE_NOT_FOUND | 文件不存在：{0} | 按 ID 找不到文件记录（全局通用） |
| 2000005 | FILE_UPLOAD_ERROR | 文件上传失败：{0} | 存储 SDK 上传异常（网络/凭证等） |
| 2000006 | FILE_STORAGE_ERROR | 文件存储配置错误：{0} | primary 指向的存储未启用或配置缺失 |

### 5.2 system 模块错误码（SystemErrorCode）

| 错误码 | 常量 | 说明 | 触发场景 |
| --- | --- | --- | --- |
| 1001701 | FILE_NOT_FOUND | 文件不存在：{0} | 删除/详情时文件记录不存在 |
| 1001702 | FILE_NO_PERMISSION | 无权操作该文件：{0} | 会员端操作非本人上传的文件 |

### 5.3 其他相关错误码（既有）

| 错误码 | 说明 |
| --- | --- |
| 1000413 | 请求体过大（超出 multipart 限制时由框架转换） |
| 1000401 / 1000403 | 未登录 / 无权限（Sa-Token 校验失败） |
